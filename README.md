# CSSBattle Solutions

My solutions to [CSSBattle](https://cssbattle.dev/) challenges. In each challenge you recreate a target image using only HTML and CSS on a 400×300 canvas.

## Structure

```
battle-01/
  01-<challenge-name>/
    index.html   # my solution
    target.png   # reference image
    README.md    # score, match %, notes
```
